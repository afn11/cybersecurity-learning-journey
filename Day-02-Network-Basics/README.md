# 🌐 Day 02 — Network Basics

**Cybersecurity Learning Journey**

Day 02 of my cybersecurity learning journey focused on building a strong foundation in computer networking.

Understanding networking is essential for cybersecurity because security tools, attacks, monitoring, and communication all depend on understanding how systems communicate.

## 🧠 Key Takeaway

The major takeaway from Day 02 was understanding how different networking concepts connect:

```text
IP Address
    ↓
MAC Address
    ↓
Port
    ↓
Protocol
    ↓
Service
    ↓
Application
```

This foundation will be important for future cybersecurity topics including:

* Network reconnaissance
* Network traffic analysis
* Vulnerability assessment
* Penetration testing
* SOC monitoring
* Web security
* Active Directory
